# What others do: sources, 12 October 2026

Source list for part 12. Collected by web search and page reads on 12 October 2026 (the GitHub API
was rate-limited, so no API star counts). Stars and dates are as the pages showed them that day.
"Unverified" means the page could not be opened and the fact comes from a search summary.

## Cloudflare to home

- https://github.com/cloudflare/workerd/issues/6740 (open since 7 May 2026): mail reaching an Email
  Worker has no Authentication-Results, Received or Received-SPF headers; ARC-Authentication-Results
  is `arc=none`; an `x-cf-spamh-score` header is present.
- https://developers.cloudflare.com/email-service/api/route-emails/email-handler/ : error-handling
  example forwards to an admin address, rejects as last resort; 25 MiB inbound limit; throw
  behaviour undocumented.
- https://github.com/imrasalghul/mailbridge (6★, v1.4.1, 6 Oct 2026): Worker encrypts to R2,
  Cloudflare Queue, home gateway, SpamAssassin, local retry queue.
- https://github.com/chawuciren/cloudflare-mail-server (126★, Aug 2026): Email Routing + Resend,
  Node.js/SQLite.
- bubblav-org/cloudflare-email-worker, bnqtoan/email2webhook: POST raw mail to HTTP. Stars not seen.
- https://github.com/Demivan/home-infra PR #98: Stalwart 0.16 replacing Email Routing, Stalwart
  publishing DKIM/MTA-STS/TLS-RPT records itself.
- Lumysia/Yggdrasil PR #42 (upstream author's Stalwart + Resend setup): 404, unverified.

## VPS relays

- https://github.com/cmer/mailcow-vps-proxy (6★): HAProxy + PROXY protocol, Postfix outbound relay
  and queue, Tailscale.
- https://github.com/RomanYsrael-cmd/mailforge : Postfix on VPS queues, forwards to Stalwart over
  WireGuard (phase 2 of its plan).
- https://github.com/markfalk/stalwart-mail-wgproxy (9★, 7 commits): EC2 + Elastic IP + WireGuard.
- pabloko gist "VPS Email Relay" (16 Aug 2025): full Postfix checks on a €1 VPS; warns against socat.

## Stalwart

- support.stalw.art, "Best practices … behind an inbound mail relay" (June 2026, maintainer reply):
  per-listener / remote_ip SenderAuth expressions, PROXY protocol, lock down the relay listener.
- https://stalw.art/docs/server/auto-ban : abuseBanRate 35/day, authBanRate 100/day, permanent
  without a ban period; no allow-list shown.
- stalwartlabs/stalwart issue #3326: bans after first expiry not enforced. Not inspected.
- support.stalw.art thread #386 (May 2026) and migration docs: stop, copy /var/lib/stalwart, start;
  --export/--import need the server stopped and are "not a substitute for proper backup procedures".
- https://stalw.art/docs/telemetry/metrics/prometheus : /metrics/prometheus, OpenTelemetry push.
- https://github.com/Souheib-h/stalwart-monitoring-stack (0★): corrected Grafana dashboard.
- https://stalw.art/docs/mta/reports/analysis : built-in DMARC/TLS-RPT/ARF analysis.
- https://github.com/sethCHN/mta-sts-proxy (0★): Worker mirroring Cloudflare's MTA-STS policy.
- September 2026 forum request for HTTP mail injection: no maintainer reply.
