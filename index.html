Running My Own Mail Server From Behind CGNAT

The homelab already serves websites through a Cloudflare Tunnel. This series is about the next thing I wanted: a real @22112002.xyz mailbox, hosted on the same VM, with no public IP of my own. It was built in one day, 8 October 2026, and the plan to rent a VPS for the public-facing half was replaced the same afternoon by a design that costs nothing.

Same rules as the Homelab guides: wrong turns stay in, every "why not X" gets answered, and I prefer a command that produces a fact over a change that produces a hope.

The shape of the thing

Email is the one service where "just put it behind the tunnel" does not work, and the first page explains why. The short version: web traffic is pulled by a browser over HTTP, which Cloudflare Tunnel is built for. Mail is pushed by other mail servers over raw TCP on port 25, which nothing at my house can accept. The morning's plan was a rented VPS as the front door. The afternoon's answer, after the budget turned out to be zero, is the one in the picture:

  • At home, on srv1: the mail server (Stalwart), the mailboxes, the spam filter, the webmail (Roundcube) and the JMAP endpoint for phones, all behind Caddy and the existing tunnel.
  • Receiving: Cloudflare Email Routing owns the MX. An Email Worker opens a TCP connection back through my own tunnel and hands each message to Stalwart on port 25, bytes unchanged.
  • Sending: Stalwart relays everything to Resend over port 465, which my ISP allows, and Resend delivers from an IP with a reputation.

Where this picks up from

If you have not read the Homelab series, the relevant facts are: there is a Proxmox host (pve, 16 GB RAM) at home behind a CGNAT connection. On it runs a Debian 13 VM called srv1 with 2 vCPUs and 1.9 GiB of RAM. srv1 runs Caddy on port 80, PHP-FPM 8.4, MariaDB, and cloudflared, which holds an outbound tunnel to Cloudflare so that 22112002.xyz and lms.22112002.xyz are reachable from the internet. Tailscale connects pve, srv1 and my laptop. None of that changes in this series.
